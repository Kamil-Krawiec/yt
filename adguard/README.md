# AdGuard Home + Tailscale Exit Node

This directory contains the whole AdGuard setup:

- `docker-compose.yaml` runs AdGuard Home in Docker.
- `ad-free` starts AdGuard and advertises this server as a Tailscale exit node.
- `turn-off-exitnode` disables exit-node advertising and stops AdGuard.
- `start-adguard` starts AdGuard without changing exit-node settings.
- `aliases.sh` contains terminal aliases.
- `install-aliases` adds the aliases to `~/.bashrc`.
- `blocklists.txt` contains recommended DNS blocklists to add in AdGuard.
- `work/` and `conf/` are generated by AdGuard and stay in this directory.

## Why Docker Only For AdGuard

AdGuard Home works well as a container because its data and config can be stored in `./work` and `./conf`.
Tailscale should stay installed natively on the host because exit-node routing needs host networking and IP forwarding.

## First Run

From this directory:

```bash
./ad-free
```

The script creates `.env` automatically using this server's Tailscale IPv4 address.
AdGuard will listen only on the Tailscale IP for:

- DNS: `Tailscale-IP:53`
- Web UI: `http://Tailscale-IP:3000`
- First-run installer fallback: `http://Tailscale-IP:3001`

Open the web UI and finish the first-time setup.

Recommended AdGuard setup choices:

- Admin web interface: all interfaces, port `3000`
- DNS server: all interfaces, port `53`
- Upstream DNS servers:
  - `https://dns.quad9.net/dns-query`
  - `https://security.cloudflare-dns.com/dns-query`
  - `https://dns.adguard-dns.com/dns-query`
- Enable DNSSEC.
- Enable cache.
- Enable blocklists from `blocklists.txt`.

## Tailscale Admin Console Steps

The script can advertise the server as an exit node, but the tailnet admin console still controls approval and DNS.

1. Open Tailscale admin console.
2. Go to Machines.
3. Find this server.
4. Approve it as an exit node.
5. Go to DNS.
6. Add this server's Tailscale IP as a global nameserver.
7. Enable Override DNS servers.

Each laptop or phone still chooses the exit node separately in its Tailscale app.
If this server is offline while a client is using it as an exit node, that client can lose internet until you select `None` as the exit node.

## Add Aliases

Run:

```bash
./install-aliases
```

After the first-time setup, AdGuard commonly moves its real web UI inside the container to port `80`.
The Compose file maps host port `3000` to that container port, so your stable browser URL remains `http://Tailscale-IP:3000`.

Then reload the shell:

```bash
source ~/.bashrc
```

Available commands:

```bash
ad-free
turn-off-exitnode
start-adguard
```

## Stop Behavior

`turn-off-exitnode` stops both exit-node advertising and AdGuard because that is the requested behavior.
Be careful: if Tailscale DNS still points to this server, stopping AdGuard may make connected devices unable to resolve domains.

Use `start-adguard` to restore DNS service without re-enabling the exit node.
